# M4.5b 방 배치 장면 예시

시나리오를 엔진과 무대에 흘려서 찍은 SVG 스냅숏입니다. 맥의 SpriteKit 화면과 같은 그림 데이터(`OfficeArt`, `CharacterArt`)와 배치 계산(`Overlay`)을 씁니다.
사무실은 폭 1120pt이고, 왼쪽 위 팀장실(유리 칸막이, 오른쪽에 출입구) 아래에 휴게 공간(소파·커피·안마 의자), 오른쪽에 파트 칸(한 줄에 2칸, 칸마다 책상 4개)이 있습니다.

## 방 배치 (`Scenarios/layout.jsonl`)

메인 세션(팀장) + 하위 세션 2개(파트장1·2). 팀장 파트원 2명, 파트장1 파트원 3명.

| 시각 | 장면 |
|---|---|
| [30.5초](layout-030.50s.svg) | 팀장 파트원은 0번 칸, 파트장1 파트원은 1번 칸(★ 자리 옆)에 앉습니다. `swift build`·`swift test`를 돌리는 파트원은 서버랙으로 가지 않고 자기 책상에서 모니터를 보며 기다립니다(⏳, 모니터 진행 표시). 웹 검색은 창가 리서치 데스크, 연속 읽기는 칸막이 오른쪽 책장 |
| [72초](layout-072.00s.svg) | 파트원이 파트장 옆으로 와서 보고합니다. 일찍 쉬러 간 파트장2는 탕비 코너 냉장고에서 음료를 꺼내 휴게 공간으로 갑니다 |
| [200초](layout-200.00s.svg) | 쉼 단계: 3분 넘게 쉰 파트장2는 안마 의자(등판 롤러가 오르내림), 팀장과 파트장1은 소파·커피 |
