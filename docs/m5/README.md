# M5(1) 행 배치 장면 예시

시나리오를 엔진 → `OfficeFloor`(화면에 보일 사람만) → 무대에 흘려서 찍은 SVG 스냅숏입니다. 맥의 SpriteKit 화면과 같은 그림 데이터(`OfficeArt`, `CharacterArt`)와 배치 계산(`Overlay`)을 씁니다.
사무실은 배율 1이고 크기는 사무실 영역(기본 창 1440×800에서 패널과 둘레 여백 20pt를 뺀 1140×708)을 따릅니다. 위쪽 뒷벽 앞에 공용 공간(정원 그림 액자, 시계, 3인용 소파 둘 · 빈 공간 · 안마 의자 둘의 휴게 공간, 화이트보드, 출입문, 냉장고·정수기·프린터의 탕비 코너)이 있고, 그 아래에 메인마다 한 행(가장 왼쪽 메인, 오른쪽 서브)을 최대 3개 놓습니다.

## 혼잡 시나리오 (`Scenarios/floor.jsonl`)

메인 4명: 메인1은 서브 12명, 메인2는 서브 3명, 메인3은 서브 1명, 메인4는 서브 2명. 서브들은 `swift build`를 돌리며 자기 책상에서 기다립니다(⏳).

| 시각 | 장면 |
|---|---|
| [30초](floor-030.00s.svg) | 한 행에 11명(메인 + 서브 10)까지 들어가 메인1 행 끝에 "+2". 넷째 메인(메인4)의 행은 3행을 넘어 그리지 않습니다 (화면에 다 못 보여 준 5명) |
| [52초](floor-052.00s.svg) | 메인1의 3번 책상 서브가 퇴근 → 숨어 있던 맨 끝 서브(서브12)가 출입문으로 들어와 그 책상에 앉고 "+1". 다른 사람은 움직이지 않습니다 |
| [80초](floor-080.00s.svg) | 메인3이 퇴근해 행이 닫히고, 숨어 있던 메인4의 행이 셋째 행으로 들어옵니다 (번호는 그대로 메인4) |
| [넓은 창 30초](floor-wide-030.00s.svg) | 패널을 숨긴 넓은 창(사무실 1400pt 폭): 한 행에 14명이 들어가 메인1의 서브 12명이 모두 보입니다 (`--size 1440x748`) |
