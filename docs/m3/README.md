# M3 사무실 장면 예시

`Scenarios/delegation.jsonl`을 엔진과 무대에 흘려서 찍은 SVG 스냅숏입니다 (`make snapshot`).
맥의 SpriteKit 화면과 같은 그림 데이터(`OfficeArt`, `CharacterArt`)와 같은 자세 계산(`RigAnimator`)을 씁니다.

| 시각 | 장면 |
|---|---|
| [10초](delegation-010.00s.svg) | 팀장이 파일을 연달아 읽다가 책장 앞으로 가서 자료를 봅니다 |
| [16초](delegation-016.00s.svg) | 팀장은 자리에서 턱을 괴고, 위임받은 code-reviewer가 승인을 기다리며 손을 든 채 자리로 갑니다 |
| [52초](delegation-052.00s.svg) | 팀원이 팀장 옆에 와서 하이파이브로 보고합니다 |
| [125초](delegation-125.00s.svg) | 응답이 끝나고 1분이 지나서 팀장이 휴게실로 걸어가는 중입니다 |

말풍선, 상태 칩, 머리 위 아이콘은 M4에서 붙습니다.
