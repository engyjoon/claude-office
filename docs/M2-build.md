# M2: 맥에서 빌드하고 확인하기

M2에서 만든 것: **메뉴바 앱**(팀별 직원 목록, 승인 대기 배지), **로컬 훅 서버**(127.0.0.1, 토큰), **훅 설치기**(설정 창 버튼), **이벤트 로그 창**.
사무실 그림(SpriteKit)은 M3에서 붙습니다. 지금은 연출 지시를 이벤트 로그에서 글로 볼 수 있습니다.

> 서버·설치기·훅 스크립트·로스터는 클라우드(Linux)에서 끝에서 끝까지 테스트했습니다 (`make test`, 95개).
> **SwiftUI 화면(`App/Sources`)은 문법 검사만 했고, 맥에서 처음 빌드합니다.** 오류가 나면 메시지를 알려 주세요.

## 1. 준비 (처음 한 번)

```bash
xcode-select -p
```

Xcode가 없다면 App Store에서 설치하고 한 번 실행해 주세요. 그다음 XcodeGen을 설치합니다.

```bash
brew install xcodegen
```

## 2. 브랜치 받기

```bash
git pull origin claude/magical-johnson-4jfy9c
```

## 3. 코어 테스트 (선택)

```bash
make test
```

## 4. 앱 빌드와 실행

```bash
make run
```

`make run`은 XcodeGen으로 `App/ClaudeOffice.xcodeproj`를 만들고, Release로 빌드한 뒤 앱을 엽니다.
Xcode에서 직접 보고 싶으면 아래처럼 프로젝트를 만든 뒤 열어서 ⌘R로 실행하세요.

```bash
make bootstrap && open App/ClaudeOffice.xcodeproj
```

앱은 Dock에 나타나지 않고 **메뉴바에 건물 아이콘**으로만 보입니다.

## 5. 처음 실행 확인표

1. 메뉴바의 건물 아이콘을 누르면 "사무실 현황"이 열립니다.
2. "Claude Code 훅이 설치되어 있지 않아요" 배너의 **설치**를 누릅니다.
   - `~/.claude/settings.json`을 백업(`settings.json.bak-날짜`)한 뒤 우리 훅만 추가합니다.
   - M0 수집 훅이 아직 있다면 그대로 둬도 서로 영향이 없습니다. 정리하려면 `python3 scripts/capture.py uninstall`.
3. **설정… → 연동 → 연결 확인**을 누릅니다. "연결 확인 완료!"가 나오면 훅 스크립트 → 앱 경로가 동작하는 것입니다.
4. **새 터미널**에서 `claude`를 실행합니다 (이미 실행 중인 세션은 훅을 다시 읽지 않습니다).
   - 메뉴에 프로젝트 이름으로 팀이 생기고 "팀장"이 나타나야 합니다.
   - 일을 시키면 상태가 "생각 중 → 실행 중 · git status → 편집 중 · 파일명"처럼 바뀝니다.
   - 권한을 묻는 명령이 나오면 메뉴바 아이콘이 ✋와 숫자로 바뀌고, 목록 맨 위에 "승인 대기"가 생깁니다. **터미널로** 버튼을 누르면 그 터미널(또는 VS Code)이 앞으로 옵니다.
   - 서브에이전트를 쓰는 작업이면 팀원이 나타났다가 끝나면 사라집니다.
5. **이벤트 로그** 창에서 받은 훅과("연출 지시도 보기"를 켜면) 사무실 연출 지시를 볼 수 있습니다.
6. **설정 → 표시**에서 표시 수준을 "요약"으로 바꾸면 파일명과 명령어가 사라집니다.

## 6. Claude Code 없이 확인하기

앱을 켠 상태에서 관찰 시나리오를 2배속으로 보냅니다.

```bash
make replay
```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 빌드 오류 | 오류 메시지 전체를 알려 주세요. 앱 층은 Swift 5 모드로 두어 동시성 오류를 줄였습니다 |
| "Claude Office.app은 손상되었거나…" | 로컬 서명 앱을 다른 맥으로 옮기면 생깁니다. 직접 빌드한 맥에서는 생기지 않습니다 |
| 직원이 나타나지 않음 | 메뉴에 "훅 스크립트를 업데이트해야 해요"가 보이면 **다시 설치** 후 새 터미널에서 claude 실행. 그래도 안 되면 이벤트 로그 창, `cat "$HOME/Library/Application Support/ClaudeOffice/endpoint"` 파일, Claude Code 안에서 `/hooks` 목록을 확인 |
| 버전 확인 실패로 기본 이벤트만 등록됨 | 로그인 셸에서 `claude --version`이 되는지. 되면 다시 설치를 눌러 주세요 |
| 훅을 완전히 지우고 싶음 | 설정 → 연동 → 제거. 다른 훅은 그대로 남습니다 |
