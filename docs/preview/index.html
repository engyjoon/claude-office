에이전트들이 일하는 작은 사무실

Claude Code 세션은 팀장으로, 서브에이전트는 팀원으로 출근합니다. 이 페이지는 docs/DESIGN.md의 아트 디렉션과 화면 구성을 미리 보여주는 시안입니다. 캐릭터는 실제 앱과 같은 방식(부위별 종이인형 리그)으로 그렸습니다.

사무실 전경

팀 섬 2개가 일하는 순간입니다. 왼쪽 팀은 편집, 파일 탐색, 권한 승인 대기를 보여주고, 오른쪽 팀은 새 팀원에게 일을 맡기는 장면입니다. 서버랙, 리서치 코너, 휴게실에도 각자 일이 있습니다.

표정 10종

눈, 눈썹, 입, 효과를 조합해서 만듭니다. 몸은 그대로 두고 얼굴 부위만 바꾸기 때문에, 에셋 몇 장으로 모든 직원에게 같은 표정을 적용할 수 있습니다.

제스처 12종

팔은 어깨, 머리는 목을 축으로 회전합니다. 숨쉬기와 눈 깜빡임은 모든 동작에 항상 깔려 있습니다.

말풍선 5종

캐릭터마다 말풍선 1개와 상태 칩 1개까지 띄웁니다. 표시 시간은 1.8초에 글자당 60ms를 더하고, 외침 풍선은 승인될 때까지 남아 있습니다.

대화 스크립트: 위임에서 보고까지

팀장이 Task 툴로 code-reviewer를 호출했을 때 화면에서 일어나는 일입니다.

이벤트에서 연출로

툴 호출은 수십 밀리초 단위로 이어지기 때문에, 한 활동을 최소 2.5초 유지하고 계속될 근거가 있을 때만 자리를 옮깁니다.

모르는 이벤트는 버립니다

Claude Code 버전마다 페이로드가 다를 수 있어서, 실제로 수집한 픽스처를 기준으로 관대하게 파싱합니다.
